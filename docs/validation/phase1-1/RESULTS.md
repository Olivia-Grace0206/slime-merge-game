## 操作と安全性

10サイズそれぞれで次の10項目を実施（合計100）。1項目内の個々のassertionや複数操作を別件として水増ししていない。

1. document寸法・正方形・中央配置・fit最大化・主要ボタン到達性。
2. 遊び方/設定/外見メニュー、40個体の番号、内部スクロール、閉じた後のフォーカス復帰。
3. ホイール拡大/縮小・カーソル中心・75/300%制限・UI寸法不変・リセット。
4. CDPの実タッチ入力に由来するPointer Eventsでピンチ拡大/縮小・中心保持・素材ドラッグ取消・残指抑止。
5. ピンチ中touchCancel/blur/3本目接触で無消費。全指離し後に新しいタッチで正常マージ。
6. ズーム＋パン後の3体マージとプレビューID/出力セル一致。
7. 同5体マージ。
8. 同11体マージ・余り全値保全。
9. ズーム＋パン後の異Tier/盤面外/Escape/pointercancel/lostpointercapture/blurの取消。
10. ドラッグ中の縦横リサイズで無消費・refit、元サイズへ戻してセル座標とマージが正常。

Phase 1回帰54項目も現行UIで再実行。プリセットを検証メニュー経由へ変更し、Tier上限期待を40へ更新。未実装の属性・生成・売却などの検証は含めない。

## 環境・制約

Node22.23.4/npm10.9.9。Playwrightは隔離ディレクトリに配置し、アプリ依存/lockfileは無変更。最新Playwright 1.62.1のChromium151アーカイブが不完全だったため、取得可能な1.51.1/Chromium134を使用。ブラウザは標準の配布ミラーから取得した。Linuxホストに日本語フォントZen Maru Gothicを準備（npm配布WOFFをTTFへ変換）、アプリは外部フォントを取得しない。フォントはアプリ/リポジトリに同梱していない。

**未確認：Windows/macOSの実Chrome/Edge、iPhone Safari実機、Android Chrome実機、iPad Safari実機、Safari/WebKit・Firefox、実端末のブラウザバー/ノッチ/OSジェスチャー、長時間使用・低性能実機のFPS。** isMobile/hasTouch、CDPタッチ、viewport回転はすべてChromiumエミュレーション。Safe Area CSSは実装済みだが実機での安全領域値は未検証。実機成功とは報告しない。

1440×900/1366×768/390×844と全40Tier比較は目視確認。CSSには常時の粒子生成やfilter/backdrop blurを使わず、発光は小さな静的shadow。表示軽減・OSのモーション削減に対応する。性能の実機ベンチマークを済ませたという意味ではない。

## 再実行

別ディレクトリにPlaywright 1.51.1とChromium shellを用意し、Build後に実行。`PLAYWRIGHT_MODULE`はその絶対パス。通常の試遊にPlaywrightは不要。

```sh
npm ci
npm run lint
npm test -- --run
npm run build
node tests/browser/phase1.cjs
node tests/browser/phase1-1.cjs
```

`BROWSER_ARTIFACT_DIR`で出力先、`GAME_URL`で既存ローカルサーバーを指定可能。未指定ならrunner自身がVite previewを起動/終了。旧版比較は`BASELINE_DIR`に開始mainのBuild済みディレクトリを指定。各スクリプトを順番に実行する。
