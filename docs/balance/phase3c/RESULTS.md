# Phase3C 数値比較 — すべて仮仕様

再現：Node22/npm10で `npx vitest run tests/balance/phase3c.test.ts`。rawはcomparison.json。10属性×Lv1/5/10/20/50/99×通常/覚醒/覚醒青/覚醒光/覚醒複合/全部重複＝360行。3覚醒までの高Lv上限はspecials.test.tsでも検証。共有設定値を記録し、正式合意とは区別する。

## 採用と比較

覚醒倍率は控えめ1.1/中間1.2/強め1.5、青は1.1/1.25/2のpower積を比較。生成に強く影響する氷/自然は覚醒1.15・青1.1、他支援は覚醒1.2・青1.25を暫定採用。売却型は炎1.25/黄金1.2/闇1.4。既存の25%/50%/40秒/属性率/変異率/重み上限を変えず、通常個体の性能を弱めない。組合せ追加保証や5体専用優遇なし。

チャージ30/60/90秒、待ち180/300/600秒、1〜3属性、3seed＝81比較。素材が供給済みの単純モデルで、10〜89秒の操作時間と10%のチャージ中断を加えた。属性数は完全覚醒個体数に影響する。盤面/素材供給は含まない。60秒・300秒待ちは短すぎる連続加工を避けつつ、1分の配置目標を作る仮値。青は既存上限下で90秒有効/180秒空白を採用、常時保証なし。これらは人のプレイ予測ではない。

## 実Core4×4・1時間・3seed

| 方針 | 覚醒/時 平均 | 最小〜最大 | 標準偏差 | 生成数 平均 | 貯蔵満杯率 平均 |

activeは紫へ3属性素材を外部から補充する加工モデル。通常マージ/ショップ購入/売却をしないため、満杯になり生成停止する。idleは無操作、fullは16体で開始するが特殊セルはスライムを占有せず、そのセルに置ける。満杯で出現できなければ延期する。各300秒で保存妥当性と特殊セル非重複を検査。素材供給や研究到達時間を見積もるモデルではない。

## 闇と安全性

消失率20/25/30/40%を各10,000組×3seedで比較し、覚醒闇30%を仮採用。売却は既存式の闇powerのみ1.4倍、闇属性と覚醒だけが確率消失する。Tier40でもGOLD上限で保護する。売却率と保持期待値を混同せず、完成後の体感・高Tier経済は継続評価する。

独立32,768配分照合と9合意例はawakening.test.ts。Quota/CAS/再ロード、紫中断、青期限での進捗率はspecials.test.ts。旧経済の長時間比較も全回帰に含む。磁力は位置重みのみでスケジュールを変えない実装、7属性/高Lvは既存上限下。実機負荷・長期間の人の育成効率は未確認。
