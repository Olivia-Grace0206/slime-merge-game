## 採用した仮設定

| 項目 | 仮設定 |
|---|---|
| 生成 / 初期容量 / 加速 | 10秒 / 10体 / 1秒 |
| 分布 | μ=1+0.92(H−1), σ=min(1.8,max(1,0.10H)), Tier1〜H |
| 売却 | 2^Tier GOLD |
| 強化 | speed12/tap16/storage20開始、1.7^Lv、上限16 |
| 強化効果 | 生成×0.9（下限2秒）、加速+0.35秒、容量+3 |
| 金イベント | 同時1個、終了/失効から60〜120秒の一様cooldown、待機45秒、700ms間隔×10 |
| 金報酬 | max(1,floor(2^Tier×0.05/(1+属性数×0.25))) /回 |

採用理由: 元の広い分布より満杯救済が減り、高Tierでも16マスに同Tierを集めやすい。高Tier寄り最大案は到達が速すぎるため中間案。金報酬の初案0.2は高額で、strictな最低属性差を確保した別試案も序盤に過大報酬を生む。整数GOLDの最小1により低Tier/属性差の同額丸めを許す0.05を採用。属性補正はTier10以上等では明確に減少。属性はPhase3まで全個体0。金なし案・頻度差と比較し、売却が主な収入となる範囲を選んだ。

## 仮のイベント・保護・保存のUX

- 金は一度対象を登録したらTier/属性数を固定し、移動・売却・素材化後も残り10回を同じ契約で払い終える。再配置で再開始しない。非表示では進行を保存し、復帰時は一度に1回だけ払い、以後700ms間隔で再開。既払い/受領額を同じセーブへ記録。待機中は占有セルにも出現し、その個体で始動する。
- 全売却に確認ダイアログ。タップ詳細から売却保護可能。保護はマージ素材を変更しない。満杯時も好きな個体を売れる。ゲームは自動売却しない。
- オフライン生成は最大容量まで。満杯時間は蓄積しない。時計巻戻りは一度時刻を合わせ、巻戻り自体では生成しない。
- Web Locks＋セーブ原文照合、重要操作ごと全状態setItem後に画面へ反映。破損/不対応は保存停止・原本保持。別タブは古い状態の書込を拒否し再読込を案内。

## 限界と調整点

3seedのbot比較は統計的に人の難易度を保証しない。Tier40時間は熟練した規則的な整理/売却が前提。高Tierでは価格に比べショップが安くなり全Lvが埋まる（以降のGOLD用途はPhase3/4）。指数価格はMAX_SAFE_INTEGER付近で操作を拒否する設計で、数日以上の無制限インフレに対する大数通貨は未実装。無操作なら盤面追加/マージがないためTierは上昇しない。実機試遊で中心/幅/生成量/ショップ/金の比率を再調整する。

GOLDの数値上限対策は仮のUXとして追加した。所持MAX_SAFE_INTEGERで売却を拒否すると満杯盤面が詰まるため、実受取額を0以上の残り余地へ制限し、確認画面に警告する。金も受取/上限超過を分けて10回を消化する。上限を超える額を隠して付与した扱いにはしない。

容量を増やすと旧Hで抽選した低TierがFIFOに長く残り、botではTier到達が遅くなる場合がある。容量はオフライン収容量の快適化であり、進化速度の保証ではない。貯蔵中個体のTier再抽選や無断破棄は行わない。gentle/steep-saleの比較は売却曲線のみ変更し、金の基準曲線は採用値へ固定した感度試験である（gentle案の金比率が極端に高い理由）。
